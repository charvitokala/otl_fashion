# Operation True Love — Fashion Analysis

A visual fashion-analysis website exploring the styling, aesthetics, and fashion influences found in the Korean webtoon **Operation: True Love**.

## Overview

**Operation True Love: A Fashion Analysis** is an interactive web experience focused on the fashion and visual identity of the characters in *Operation: True Love*.

The project examines how the series incorporates **Y2K fashion**, early-2000s Korean streetwear, feminine casual styling, and nostalgic accessories into its character designs.

The website presents this analysis through a retro computer-interface-inspired design, creating an experience that complements the early-2000s fashion being discussed.

## Getting Started

### Prerequisites

Make sure you have:

* Node.js
* npm, pnpm, or yarn
* Git

### Installation

Clone the repository:

```bash
git clone <your-repository-url>
cd otl-fashion
```

Install dependencies:

```bash
npm install
```

### Run Locally

Start the development server:

```bash
npm run dev
```

Open the local development URL shown in your terminal.

## Production Build

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

> The available commands depend on the project's `package.json`.

## Navigation

The experience is structured as a sequential analysis, allowing visitors to move through different sections using the **NEXT** navigation.

This creates a presentation closer to an interactive editorial or digital magazine than a conventional single-page article.

## Deployment

The project is currently deployed through **Cloudflare Pages**.

Production URL:

```text
https://otl-fashion.pages.dev/
```

For deployment:

1. Push the project to a Git repository.
2. Create a Cloudflare Pages project.
3. Connect the repository.
4. Configure the framework/build settings.
5. Deploy the project.
